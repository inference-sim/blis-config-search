01 · SEARCH

BLIS sweeps the config space

For a model, hardware, GPU budget and workload, config-search simulates tensor-parallel width, instance count, PD split, expert parallelism and engine knobs, then keeps the Pareto-optimal set under an interactivity floor.

02 · REPORT

A run directory becomes one HTML file

report.py turns run-dir → index.html: a self-contained interactive report with the winner, the full tradeoff curve and every finalist. Each point above opens its own at <run_id>/index.html.

03 · ADD YOURS

Open a PR, CI does the rest

Run config-search locally for your model and budget, then open a PR adding the run directory. CI regenerates the report and this gallery, and a new point appears on the plot after merge.

Simulator predictions, not measurements. Every number here comes from BLIS, a discrete-event simulator of LLM serving. Treat it as a ranked shortlist: validate on real hardware before committing capacity. Scenarios tagged mock (dashed, hollow markers) are illustrative placeholders, not BLIS output.
