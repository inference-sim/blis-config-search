muse-spark-open-816b-a42b-nvfp4 on 8x h200: muse-spark-open-816b-a42b-h200-agentx-8gpu

A deterministic sweep over inferencex-agentx-mvp traffic, comparing 7 designs on one GPU budget.

BLIS discrete-event simulationExperiment Spec (RFC #21)deterministic sweep — no LLM in the measurement pathseed 42

What was tested

46 configurations over 7 sweeps (topology-pp, topology-dp, batch-caps, kv-capacity, moe-collective, prefill-chunking, cudagraph), each at 5 load levels, every run on exactly 8 GPUs.

What was found

1x TP8 + EP (gpu mem util 0.95 · KV dtype fp8), from the kv-capacity sweep, reached 35.31 tok/s/accelerator (282.5 tok/s across the fleet) at concurrency 32 while holding the scenario's SLOs.

What to run

1x TP8 + EP (gpu mem util 0.95 · KV dtype fp8) at concurrency 32. 225 of 230 runs held the SLOs.

1The measurements

Every run in this experiment is in the explorer below: filter by outcome to see which settings held the SLOs, or by setting to compare one sweep against another.

Each sweep's hypothesis was written before the runs, and is quoted beside that sweep's measured result below.

2Sweep: topology-pp

TP8 should peak highest, since every pipeline stage adds a boundary hop to each decode step.

Measured: best was 1x TP8 + EP at 27.46 tok/s/accelerator (concurrency 32).

3Sweep: topology-dp

Data-parallel attention should beat pipeline stages at the same tp, and EP should matter more at dp 4 than dp 2.

Measured: best was 1x TP4xDP2 + EP at 14.42 tok/s/accelerator (concurrency 32).

4Sweep: batch-caps

A seq cap of 8 should bind on TP8 but not on TP2 DP4, whose four attention ranks each see a quarter of the lanes.

Measured: best was 1x TP8 + EP (max seqs 16 · batch tokens 16,384) at 27.84 tok/s/accelerator (concurrency 32).

5Sweep: kv-capacity

fp8 KV and higher memory utilization should substitute on TP8 but add on TP2 DP4, which replicates attention weights.

Measured: best was 1x TP8 + EP (gpu mem util 0.95 · KV dtype fp8) at 35.31 tok/s/accelerator (concurrency 32).

6Sweep: moe-collective

DeepEP low-latency should win on TP8, and the gap should shrink on TP2 DP4, where sequence-parallel MoE splits the batch.

Measured: best was 1x TP8 + EP at 27.46 tok/s/accelerator (concurrency 32).

7Sweep: prefill-chunking

Capping long prefills should trade a little peak throughput for a much lower ITL p99 at saturation.

Measured: best was 1x TP8 + EP (prefill chunk 8,192) at 27.46 tok/s/accelerator (concurrency 32).

8Sweep: cudagraph

FULL-family capture should beat the PIECEWISE default by a few percent, and NONE should collapse.

Measured: best was 1x TP8 + EP (graph capture full) at 27.99 tok/s/accelerator (concurrency 32).
