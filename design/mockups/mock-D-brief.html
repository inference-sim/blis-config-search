config-search · deployment briefs

What to run, per model, GPU budget and workload. Each brief links to a full interactive report of the Pareto-optimal serving configurations.

Simulator predictions, not measurements. Validate on real hardware before committing capacity.

01How a report is made

A search sweeps tp / instances / PD / EP and engine knobs in the BLIS simulator, keeps the Pareto-optimal set, and report.py turns the run directory into one self-contained index.html. No server at view time.

02Add your own

Run config-search locally for your model and workload, commit the run dir, and open a PR. CI rebuilds every report and this gallery, then publishes to GitHub Pages.

03Trust note

Every number is a simulator prediction at a usable operating point, not a live measurement. Validate on real hardware before committing capacity. Scenarios tagged mock are placeholders, not BLIS output.
