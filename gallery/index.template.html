How a report is made

config-search sweeps tp, instances, PD and EP in the BLIS simulator, keeps the Pareto frontier under your interactivity floor, and report.py turns the run dir into a single self-contained index.html. No server runs at view time.

Add your own scenario

Use the Submit tab to build a scenario.yaml, then open a PR. CI regenerates every report and this site after a maintainer approves the run.

How to read the numbers

Recommended config is the most output tok/s on the budget that still holds the per-user floor on every instance. Open a scenario to see the finalists it beat and every run behind it.

Trust note. All figures are BLIS simulator predictions, not benchmarks of a live cluster. Validate a short-listed config on real hardware before committing capacity. Rows flagged mock are illustrative placeholder data, not BLIS output.
